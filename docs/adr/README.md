# Architecture decision records

These records capture the decisions that shape Grumpo and the reasons behind them, so that a future contributor can tell a deliberate constraint from an accident. Each record opens with a single line giving its status and date, followed by the same short form of context, decision and consequences. A decision that is later reversed is not edited away, and instead gets a new record that supersedes the old one.
