# 0014. The daemon is renamed grumpod, and the installer migrates focusd

Accepted on 2026-10-13. Supersedes the part of [ADR 0012](0012-grumpo-rebrand-and-block-screen.md) that kept the daemon's identity.

## Context

ADR 0012 renamed the app's identity and kept the daemon's, on the grounds that the daemon is a name nobody reads, while renaming it would strand the installed daemon and its rules. The owner disproved the first half the day after. Reading `/etc/hosts` to find out why YouTube would not load, they found a block marked `# >>> focus: managed block, do not edit >>>` listing every site they had blocked, took it for the leftover of an old browser extension and asked how to delete it by hand. The hosts file is exactly where a person looks when a site fails to load, and a block there under a name they do not recognize looks like something foreign to remove, which is the opposite of what a blocker needs. The same old name appears in Activity Monitor as `focusd`, in `/Library/Application Support/Focus` and `/Library/Logs/Focus`, and in the log folder the app writes under `~/Library/Logs/Focus`. The second half still holds, since only version 0.1.0 has shipped with the old names, so renaming now strands as few installs as it ever will.

## Decision

Every name a person can see becomes Grumpo's. The daemon's crate, binary, code signing identifier and LaunchDaemon label become `grumpod` and `io.github.brian-rey-development.grumpod`, its state and logs move to `/Library/Application Support/Grumpo` and `/Library/Logs/Grumpo`, its socket and install lock become `/var/run/grumpod.sock` and `/var/run/grumpod-install.lock`, its environment overrides become `GRUMPOD_STATE_DIR`, `GRUMPOD_HOSTS_FILE`, `GRUMPOD_SOCKET` and `GRUMPOD_LOG_FILE`, the hosts markers read `grumpo: managed block`, and the app logs to `~/Library/Logs/Grumpo/grumpo.log`. Names nobody outside the code reads, such as the `focus-core` and `focus-app` crates, `FOCUS_SIGNING_IDENTITY` and the concept of focus time, stay as they are.

The installer migrates an install made under the old name with the same three steps it already uses for `focus-hosts`, in `scripts/lib/focusd.sh`. After stopping any `grumpod` and creating the new folders, it stops `focusd` and copies its `state.json` into the new state folder unless one is already there, because a state file `grumpod` wrote is newer. The copy leaves the original untouched, so the rollback that removes the new state file and restarts `focusd` returns the Mac to exactly where it was. Only after `grumpod` answers does the installer delete the old label, binary, newsyslog entry, socket, state and logs. The hosts block needs no step of its own, because the daemon treats the old markers as a third kind of block it replaces, next to its current one and the `FOCUS-HOSTS` block of `focus-hosts`, so its first write after starting removes the old block and writes the new one, and the sites stay blocked throughout. The uninstaller removes a `focusd` it finds as well, and a `state.json` left in the old folder by an uninstall without `--purge` still counts as an install to migrate, so a later install carries those rules over.

The app looks for the daemon at the new socket. When nothing answers there but the old socket exists, it reports the service as outdated instead of missing, so a person who updated the app while `focusd` still runs sees Update service and the truth that blocking continues, and the same password prompt that installs the service performs the migration.

## Consequences

A person upgrading from 0.1.0 enters their password once to update the service, and keeps their rules, unlock state and blocked sites throughout. The usage history lives in the app's data folder, which this decision does not touch. The app's old log folder `~/Library/Logs/Focus` is left behind with at most seven days of logs, since deleting files in a person's home folder to tidy a name is not worth the risk. The earlier ADRs and changelog entries keep the old names, because they record what was true when they were written, and this record explains the change to anyone who meets `focusd` in them.
